# Brand assets

| File | What |
|---|---|
| `banner.png` / `banner.svg` | Repository banner, 1280 × 640 (exported at 2×). Also the right size for GitHub's social preview (Settings → General → Social preview). |
| `logo.png` / `logo.svg` | The CorpSEC mark on its own: the app's inspection seal with "A+", transparent background. |

Both SVGs are generated by `make_banner.py`; edit the script, not the SVGs:

```bash
python3 docs/assets/make_banner.py
rsvg-convert -w 2560 docs/assets/banner.svg -o docs/assets/banner.png
rsvg-convert -w 512 docs/assets/logo.svg -o docs/assets/logo.png
```

The text uses [Fraunces](https://fonts.google.com/specimen/Fraunces) Bold (opsz 72) and [Public Sans](https://fonts.google.com/specimen/Public+Sans) Medium/Bold, the web app's fonts (SIL Open Font License). Install them first, or the PNGs fall back to other fonts. The PNGs are what GitHub shows; the SVGs reference the fonts by name and only look right where those fonts are installed.

Colours come from the web app's dark theme (`apps/web/src/app/globals.css`): background `#121a28`, accent `#6fc2ad`, text `#eee8dc`; the logo uses `#1d8a74` so it reads on light and dark backgrounds.
